# ベルトアクションの拡張方針

敵の数を増やすだけでなく、プレイヤーが狙う順番・位置取り・反撃のタイミングを変えられる構成にする。

| アイディア | 今回の実装 | 狙い |
| --- | --- | --- |
| 敵同士の役割分担 | 盾兵の後ろに砲撃兵、騎兵と飛行敵、指揮官と子分 | 優先して倒す相手を選ぶ |
| ジャンプ攻撃する敵 | LEAPER。予告位置に跳び、着地後に隙を作る | 空中・地上の切り替えを読む |
| 後方支援 | ARTILLERY。予告地点へ放物線の砲弾 | 足を止めず奥行き移動する |
| 騎兵 | STRIDER。機械四脚のマウントで直進し、破壊後は徒歩に変化 | 強敵との戦いに段階を作る |
| 小さな子分を連れる敵 | COMMANDERは2体のMINIONを伴う。撃破で子分が一時混乱 | 集団戦の突破口を明確にする |
| 中ボス | 第2・第4ステージのTHE WARDEN | 終盤までに装甲破壊と予告回避を習得する |
| 飛行敵 | DRONEの巡航高度と下降突撃 | 上攻撃・空中攻撃に役割を持たせる |
| ワールドマップ | 現在地、制圧済み、未到達、各区画の敵と遭遇名を表示 | キャンペーンの目標と距離感を作る |
| 区画間の補給 | 修復40ポイント / 火力倍率+0.08 / 残機+1（最大4）を1つ選ぶ | 次の戦闘に向けて判断する |

ステージ構成は製造区画→輸送区画→空中回廊→群体制御区画→量産兵団→包囲回廊→中央制御区画。計23戦闘。新敵の単独導入から複数の役割が混ざる編成へ段階的に進める。景観・設備配置・配色を区画ごとに変え、既存の3Dモデル素材を共有する。

ワールドマップは直線ルート。途中の区画を飛ばしたり、補給を繰り返し取得したりはできない。キーボード・ゲームパッドのみでも右のゲートを通って進行でき、その場合は修復が自動選択される。再挑戦時は最初の機体性能へ戻す。

今後の候補は分岐ルートと危険度別の報酬、護衛、敵の投げ返し。今回の区画目標と技データ契約は下記。

検証では、敵の予告がプレイヤーを追尾し続けないこと、中ボスでゲームが終了しないこと、全ステージを通常入力だけでクリアできること、マップ中の停止・復帰、補給とリスタートの整合性を確認する。描画の合成テストは実GPUの性能・長時間の人間による難易度評価を代替するものではない。

## 戦闘拡張

スマッシュは専用入力のみ（キーボードK）。敵は場外で一度だけ、無敵なしのブースト復帰を行い、着地で再使用可能になる。ボスの重量係数は3.6、中ボスは2.6。床のレーン・十字・時間差掃射を予告してから発動する。予告矩形と当たり判定は同じデータを使用し、ポーズ・次区画・ボス撃破にも連動する。

狙撃兵は細い横断ビーム、工作兵は低い地雷爆発で移動を促す。第5区画は4波の軍団戦。ステージ横幅28、区画間隔34で移動距離も広げる。軍団も共有ディレクターの攻撃予約に従い、範囲攻撃と設備の連鎖爆発を活かす。


## Combat architecture / diversity

- `director.ts` は役割を ranged/support/defender/flanker/boss に分け、SCREEN（射線と盾の前衛）、FLANK（側面からの接近）、REGROUP（攻撃しない再編）の順に進める。待機中フランカーは別の奥行きへ、援護兵は後方へ、盾兵はプレイヤーのレーンへ寄る。ラベルで行動を可視化する。
- 全体で1つの危険予約。攻撃が中断されても発射済みの弾・床予告が残れば次の攻撃を開始しない。終了後 .4 秒の間を残し、さらに再編段階を設ける。参加者が消えた予約は掃除し、該当役割がいなければ別役割が動ける。区画・波・再起動で予約をリセット。
- 最終ボスの装甲破壊は勝利ではない。一度だけ1.4秒の無敵・攻撃停止へ入り、古い弾と床予告を消す。その後の OVERDRIVE は PINCER（外側からの挟撃、中央通路が残る）、PULSE FAN（固定照準の3方向弾）、OVERLOAD（安全レーンが時間差で移る床）を循環する。床は最大6面、追加の無限増援はない。低画質でも予告を省略しない。中ボスはこの移行を行わない。
- 第1区画 RELAY: x=±8、z=±1.5 の通信リレー2基、各18HP。第3区画 LOCKDOWN: 18秒生存、6/12秒に2体ずつの増援、同時最大14体。第6区画 NODES: 同位置の制御ノード2基、各32HP。プレイヤーの攻撃・弾・プレイヤー起因の設備爆発で破壊できる。敵の通常技・弾・迫撃砲・敵起因の連鎖爆発では壊れない。目標だけ／敵だけを先に完了してもゲートが待機し、両方で開く。目標報酬250は一度だけ。
- 上Lは全ロードアウト共通の復帰を保持。ニュートラルの3系統すべてに機能差のある2モジュールを持ち、横Lと下Lも独立抽選。表示とシミュレーションは同じスロットを読む。初期ロードアウトを深くコピーし、再挑戦のたびに再構築する。
- 奥・手前は落下のないレール。物理変位直後にzを制限してから床交差を解決し、設備・つかみの後も制限する。左右場外・縦撃墜・下からのすり抜け禁止は維持する。

通常入力だけのキャンペーンbotは全7区画を遊び、リレー／ノードへ歩いて攻撃し、ロックダウンと増援を処理する。試験用の進行フラグを直接成立させない。botは人の長期プレイや全シードの難易度保証を代替しない。技の追加と判定の座標契約は [combat-architecture.md](combat-architecture.md)。
